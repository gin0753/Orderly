# Google branding assets

Retrieved 9 October 2026 from Google's [official branding guidelines](https://developers.google.com/identity/branding-guidelines).

- `google-sign-in-light.png`: unmodified 720×160 Android + Web, PNG @4x, Light, Show text=Yes, Shape=Square from https://developers.google.com/static/identity/images/signin-assets.zip. Render at 180×40, preserving aspect ratio and artwork.
- `google-g.png`: unmodified official standard-color G from https://developers.google.com/static/identity/images/g-logo.png. Used beside the Google connected-method label and explicit Connect Google action, on white.

These assets remain subject to Google's branding rules. No OAuth SDK or remote runtime asset loading is introduced.
